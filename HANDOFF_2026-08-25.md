## 2. The measurement method that finally worked

Three earlier methods were wrong and are recorded as such:
local wall-clock (>=20% noise, CLAUDE.md's own gotcha); `m67e_rf48.py`'s kappa
(L159: wrong per case by up to 8x); and mixing Windows walls with a
WSL-calibrated `f` (my error, withdrawn — WSL runs the same configuration
3.0-4.1x slower than Windows).

What works — **`f` never appears**:

```
t_ours_grader(n)  =  t_beta(n) * w_ours(n) / w_m73(n)
```

Both walls on ONE box, same day, same flags; `t_beta(n)` is the grader's own
per-case runtime for M73. Machine speed cancels. M73's wrapper is
`git show 7f38893:optimizer_constructive.py`, kept in `_m73win/`.

**Route A OFF in every measurement arm.** It is verified result-neutral (single
cases bit-identical on/off; L177 det1 vs det2 matched 100/100 on cost AND
positions with it live) and costs 2.9x on this 16-physical-core box.

## 3. What is implemented in the tree

**(a) `_L157_DEPTH` -> all 1s.** Passes 2-3 buy +0.338% of quality for +16.7
grader-seconds = **-6.6pp of RF**, net negative in BOTH route-A scenarios.

**(b) `_L196_LPGATE`** — per-block-count 0/1, s = 1.2, plus `_lp_gate_ok()`
consulted by `_shape_lp_maybe` before the LP runs at all.

```
run the LP on block count n  iff  t_pool(n) + dt_lp(n) <= 0.3046 * M(n) * 1.2
```

Fires on **63 of 100** block counts, **8 of them n>100**. (s=1.0 fires on 30, of
which only 2 are n>100 — it keeps cheap small cases and skips exactly where the
LP earns, capturing 12% of the LP's OOS quality. That is why s=1.2 wins.)

Both are **code defaults, not env vars** — the grader strips `ICCAD_*`, so an
env-only mechanism is inert in the package however green it measures (L158).
Kill switch `ICCAD_LP_GATE=0` -> LP everywhere.

⚠️ The fork's notes call this table `_L195_LPGATE`; the tree calls it
`_L196_LPGATE`. Same table, same s.

**VERIFIED LIVE** (`_l198_*`, 100 cases each):

```
gate on  (default)        LP ran on  63 cases   == the table
gate off (ICCAD_LP_GATE=0) LP ran on 100 cases   == kill switch works
```

`ICCAD_SHAPE_LP_STATS` only writes a line when the LP actually executes, so the
line count IS the liveness proof. A table that silently kept old values would
pass determinism and the kill switch while changing nothing — the failure this
project records most often.

+1.050% on s1). Two sessions reached it separately.

## 5. 🚨 Route A is a BET and will stay one

`_shape_lp_on()` fires on the same >=40-core gate as route A, deliberately — the
LP is only affordable because route A is supposed to shorten the wall.

* Route A has **never run on the grader**. Beta was M73, which lacks it.
* Its **-32.2% at 48 real cores is a projection**, never a measurement.
* On this box's 16 physical cores it **costs 2.9x**.
* The ledger separately records it sinking every case to SA fallback at 48
  cores, and hanging 600 s on a pre-L108 binary.

**It cannot be measured here and both school machines are unavailable
(confirmed 2026-08-25). This is closed: it stays a bet.**

Do not retry local timing to settle it: single-case wall on this box varies
**23-55% run to run**, which swamps the 1.2-1.5x effect. `ICCAD_ADAPTIVE_CORES=48`
does **not** simulate 48 cores — it only makes `_effective_cores()` return 48,
selecting the 48-core pool and switching the cores-gated tiers on. Throughput
stays whatever the box has. That is why `l113_ship_gate --cores 48` and
`l117_linux_verify final48` verify the 48-core *configuration* correctly while
their wall times mean nothing for the grader.

## 9. Reusable lessons

* **Never act on an in-set null.** The twins moved 0 of 100 in-set cases with
  identical positions and are worth +0.67% OOS.
* **A mechanism's number is only valid in the configuration it was measured in.**
  L171 flipped sign when the depth map changed underneath it.
* **Every offline-derived advantage shrank or reversed when measured OOS** —
  four for four across these sessions.
* **`f` is avoidable.** Same-box ratios against `t_beta` need no machine
  constant. Use that, not wall-clock, not kappa.
* Two agents on one box destroyed four measurements. Every script here takes a
  lockfile; keep it that way.
